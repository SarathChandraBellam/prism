# Code of Conduct

Prism adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

All participants are expected to follow it in every project space, including issues, pull requests, discussions and any other channels.

## Reporting

To report unacceptable behavior, contact the maintainers privately through the contact listed in [SECURITY.md](SECURITY.md). All reports will be reviewed promptly and handled confidentially.
